# APPENDIX C — FIVE-DOCUMENT CROSS-REFERENCE INDEX

**Trady Perch Product Implementation Constitution · Appendices**

**Inherited From:** UX / Experience Blueprint Chapter 7 (Three Pillars Relationship) and Brand Identity Manual Chapter 3 (Three-Layer Model) — both extended here to the full six-document hierarchy this Constitution completes.

*The master lookup tool for one recurring question: for any implementation decision, which of the six constitutional documents actually holds the answer? Use this appendix before searching — it routes the question, it does not answer it.*

---

## 1. HOW TO USE THIS INDEX

Per Chapter 1's IP1, every implementation decision traces to a specific origin. This appendix is the fastest path to that origin: find the kind of question being asked in Section 2's table, and go directly to the document and chapter range it names, rather than searching across all six documents individually. Section 3 then gives the reverse view — which upstream chapters each Part of this Constitution draws from most heavily, for the case where the starting point is a Constitution chapter rather than a raw question.

## 4. WHEN TWO DOCUMENTS SEEM TO DISAGREE

Per this Constitution's own §0.1 standing rule, restated here as this appendix's own closing instruction: the fixed authority order is Master Vision → Design System Bible → Motion Bible → UX / Experience Blueprint → Brand Identity Manual → this Constitution. Where a genuine conflict is found between two upstream documents themselves (not merely between this Constitution and one of them), it is not resolved informally at the point of use — it is raised through Chapter 64's governance path as a gap in the five documents' own mutual consistency, since this Constitution has no authority to adjudicate between documents above it.
