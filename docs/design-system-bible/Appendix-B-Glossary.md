# APPENDIX B — GLOSSARY

**Trady Perch Design System Bible · Appendices**
*A living reference. First compiled at the close of this Bible's authoring; updated whenever a new term of art enters the system.*

---

**Anti-Pattern** — A named, documented failure mode, added to Chapter 68's library only after a real, observed instance (Ap-3), never speculatively.

**Blast Radius** — How many downstream chapters or shipped components a proposal would affect if incorrect; the basis for Chapter 65's Gov-4 three-tier approval structure.

**Ceremonial (motion tier)** — The slowest, most deliberate of Chapter 15's five motion tiers, reserved exclusively for the intro sequence (Mt-3); using it anywhere else is a direct violation regardless of how significant the moment feels.

**Component Tier** — The most specific of Chapter 2's three token tiers, scoped to a single component's own context; requires the highest evidentiary bar of the three (T-4) since it is the tier most prone to uncontrolled proliferation.

**Core Tier** — The first of Chapter 2's three token tiers: raw, literal, physical values (an exact hex code, an exact pixel measurement), defined once and referenced everywhere else.

**Derivation Test** — Chapter 1, Section 4's five-step procedure for resolving any design question not already answered by a more specific chapter: identify the question, check for existing governance, test against P1–P7, resolve conflicts via P8, document the result.

**Design Debt** — A tracked, prioritized gap between the system's current state and its documented ideal, per Chapter 69 — never left as an unreviewed "known issue."

**Diegetic Motion** — Chapter 1's Principle 6: motion that represents something real (a relationship, a state change, a sequence) as opposed to motion existing purely for visual effect.

**Emphasis (Button axis)** — Chapter 18's closed, three-value variant axis: Primary, Secondary, Ghost — never a fourth value.

**Gold Budget** — Master Vision §7.4's model for spending the system's 10% gold-coverage ceiling deliberately across a sequence rather than checking it once per screen in isolation; Chapter 3's C-5 formalizes the audit method.

**Interaction State vs. Content State** — Chapter 39's two families of the eight canonical states: Hover/Focus/Active/Disabled (interaction-driven, transient) versus Loading/Error/Success/Empty (data-driven, persistent).

**One-Brand Test** — Master Vision §25.10's test: if the logo were removed from any brand surface, would it still be recognizable as Trady Perch's? Applied throughout this Bible to everything from dashboards to the Bible's own presentation layer (Appendix A).

**Reduced-Motion Companion** — The paired, alternate value every Chapter 15 motion-duration token carries from the moment it is defined (Mt-4), satisfying Master Vision §9.5's Reduced Motion Contract automatically rather than as a bolted-on afterthought.

**Resolution Question** — Chapter 2's core test for placing any new token: "at which tier does this value's reason for changing actually live?"

**Review Board** — Chapter 65's ad hoc body of currently active contributors (Gov-6), convened for Structural and Foundational decisions; not a fixed, permanent committee.

**Scarce Signal, The** — Chapter 1's Principle 3: a signal's value is a function of its scarcity, not its intensity — the reasoning underlying the Gold Budget, badge-color discipline, and cursor-effect zone restriction alike.

**Semantic Tier** — The second of Chapter 2's three token tiers: role-based names ("accent.primary") that reference a Core value without restating it, surviving a Core-tier change without needing to be renamed.

**Sequence-Aware Correctness** — Chapter 1's Principle 5: a design decision's correctness depends partly on its placement in a larger sequence of doubts and feelings (Master Vision Chapter 4), not on its own execution in isolation.

**Ten-Year Test, The** — Chapter 74's closing, three-facet synthesis test every future addition to this system must pass: does it still serve the eight principles' substance, would removing it make the system more or less honest, and does it make the brand look like it needs to try harder to be believed.

**Tier 1 / Tier 2 / Tier 3 Principles** — Chapter 1, Section 4's three-level principle model: Tier 1 is Chapter 1's own eight universal principles (P1–P8); Tier 2 is a Volume-level principle set; Tier 3 is a chapter-specific principle set, required to cite its Tier 1 ancestry.

**Tier-Shopping** — Chapter 65's named anti-pattern: classifying a Structural or Foundational proposal as Routine to avoid the higher-consent process required for its actual blast radius.

**Traceable Inheritance** — Chapter 1's Principle 1: every design decision must be traceable to a specific, named origin — a Master Vision section or a numbered principle — never existing because "it looked right."

**Trust Equation** — Master Vision §2.3's four-input model for how a prospect builds trust in this brand, in order of weight: outcomes, process rigor, technical depth, aesthetic polish.
